What’s new in watsonx Orchestrate: April highlights and early May updates (2026)

By watsonx watsonx Orchestrate Blog Team posted 13 days ago

  
Like

The releases in April and early May of IBM watsonx Orchestrate deliver enhancements that make it easier to collaborate across teams, manage workflows with confidence, and design richer agent interactions.

Add MCP servers from the catalog

Builders can now discover, connect, and add remote Model Context Protocol (MCP) servers directly from the catalog, making it easier to extend agent capabilities with external tools, without manual setup or custom integration work.

With MCP server catalog support, you can:

  • Browse and discover remote MCP servers from the catalog
  • Filter by category and search by name or description
  • View MCP server details, including provider information and supported tools
  • Connect to MCP servers using existing connections
  • Select and add specific tools from a connected MCP server to your agent
  • Manage MCP servers, including editing details or removing them
  • Purchase locked MCP servers to unlock and connect premium offerings

This feature allows teams to quickly enrich agents by integrating tools from providers such as Box, Moody’s, and other partners, accelerating development while maintaining a consistent and governed experience. Learn more about Exploring MCP servers.

Smarter user assignment and reviews

Builders can now configure recipients for user activities using native user pickers in forms and chat, ensuring tasks reach the right people at the right time. In addition, assigning users to document processing reviews is now generally available, enabling reliable human‑in‑the‑loop validation for document extraction and classification workflows. Learn more about Configuring the recipient for a user activity.

More flexible and maintainable connections

Connections now support additional runtime parameters, allowing teams to centrally manage tenant‑level execution context, such as project or organization IDs, without changing authentication credentials. This simplifies configuration and improves maintainability at scale. Access Authentication types overview.

Deeper visibility in flow builder

Flow builder continues to evolve with features that improve understanding and troubleshooting of workflows:

  • View pro‑code workflows created with the ADK as read‑only visualizations
  • Inspect historic flow versions to see exactly how a workflow ran at a point in time
  • Onboarding guidance to help new users quickly get oriented and productive

Together, these updates give teams greater transparency and confidence as workflows grow in complexity.

Explore more details of April/May release!

Read the full What’s new release in the official IBM documentation.
