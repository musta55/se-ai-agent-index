watsonx Orchestrate News | A Technical Touchpoint May 2026

By Gustavo Villegas posted 14 days ago

  
Like

Welcome to your new monthly watsonx Orchestrate newsletter!


This month’s edition highlights two standout features: task recipient assignment and document processing reviews. Plus, we’re previewing an upcoming Ask Me Anything where our watsonx Orchestrate product team will answer your questions about what is being announced this week at IBM THINK 2026 (May 4-7).  🚀

Feature Highlights:

Configure the Recipient for a User Activity

As your agentic workflows grow more complex, routing the right task to the right person becomes just as important as automating the task itself. User recipient configuration solves that. Instead of sending work to a shared queue and hoping someone picks it up, you can now designate exactly who should review, approve, or complete a task directly from within the workflow, using a native user picker widget in form.

  • Configure single-user or multi-user selection modes
  • Search for users by name or email address
  • Set minimum and maximum selection requirements
  • Use user pickers in both form fields and chat interactions

 Read the full feature details here

Assign Users to Document Processing Reviews - Generally Available

Document processing rarely goes perfectly every time, confidence thresholds get missed, edge cases surface, and someone needs to step in and validate. Now you can define exactly who that someone is. Assign specific users to review extraction or classification results when human intervention is required, and the workflow picks back up automatically once they submit.

  • Trigger reviews based on extraction confidence thresholds or empty values
  • Select specific fields that require human review in document extractors
  • Route classification reviews when documents are classified as “Other”
  • Receive chat notifications and submit reviews to continue the workflow

Read the full feature details here

What's New

Latest watsonx Orchestrate Release: Human-in-the-Loop, Smarter Forms, and Agentic Interoperability

The May 2026 release puts human oversight and structured interaction front and center. Beyond the two featured highlights, this release introduces native form widgets in agent chat - text boxes, radio buttons, date pickers, tables, and file upload/download, giving builders direct control over how users interact with agents. Dynamic forms take this further, adapting in real time based on user input so a single form can serve multiple use cases without branching into separate flows.

Flow builder adds two powerful observability upgrades: view pro-code ADK workflows as read-only visualizations alongside the flow inspector, and display the exact historic version of a workflow that ran during any past execution. New onboarding cards guide first-time flow builder users through key capabilities.
On the connectivity side, connections now support additional runtime parameters tenant IDs, project IDs, and org identifiers without touching authentication credentials. And the Agent-to-Agent (A2A) protocol opens watsonx Orchestrate to cross-platform agentic communication, enabling external systems to discover, message, and task agents through a standardized interface.

Ready to explore everything in this release?

Learn more here

New in the ADK: Python Toolkits, Error Handling, and Form Tools

The watsonx Orchestrate ADK version 2.8.0 is now available. Create Python toolkits that bundle multiple tools for streamlined imports, configure error handling directly in agentic workflow flows for more predictable failure response, and display native form widgets from tools using the new form tool capability. Security gets an upgrade too, file uploads and downloads now use authenticated access instead of pre-signed URLs, and OAuth Client Credentials authentication is available for virtual models through the AI Gateway.
